# Acupuntura-

Acupuntura para Equilibrar Corpo e Mente A acupuntura é uma prática milenar da Medicina Tradicional Chinesa que busca restabelecer o equilíbrio natural do corpo, promovendo saúde física, mental e emocional.

Sistema web desenvolvido com **Python e Django** para gerenciamento de informações relacionadas a atendimentos de acupuntura.

Este projeto foi criado com o objetivo de **praticar desenvolvimento Back-End**, organização de código e boas práticas utilizando ferramentas modernas do ecossistema Python.

---

# 💻 Executando localmente

### 1️⃣ Clonar o repositório

```bash
git clone https://github.com/david0407j/Acupuntura-.git
```

---

### 2️⃣ Entrar na pasta

```bash
cd Acupuntura-
```

---

### 3️⃣ Instalar dependências com Poetry

```bash
poetry install
```

---

### 4️⃣ Ativar ambiente virtual

```bash
poetry shell
```

---

### 5️⃣ Rodar migrações

```bash
python manage.py migrate
```

---

### 6️⃣ Executar servidor

```bash
python manage.py runserver
```
